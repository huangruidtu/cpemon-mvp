## One-Sentence Project Story

CPEmon turns a YAML-first Kubernetes monitoring MVP into an EKS-oriented
platform with GitOps delivery, Kafka event flow, progressive rollout safety,
observability, policy, cost visibility, developer self-service, and
AI-assisted troubleshooting boundaries.
